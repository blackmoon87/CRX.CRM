// FAQ

Frequently Asked Questions

Got questions? We've got answers.

How does CRX CRM achieve a 2MB memory footprint? +
CRX is built on the Spartan MVC architecture, which strips out bloated framework overhead, heavy reflection layers, and redundant dependencies. It boots in under 1.5ms and uses optimized single-pass routing and efficient PDO SQLite/MySQL query builders.
Can I use MySQL or PostgreSQL instead of SQLite? +
Yes! CRX natively supports MySQL, MariaDB, and SQLite through environment configuration in your .env file. Changing DB_CONNECTION=mysql immediately switches dialects without altering your business logic.
What is the Model Context Protocol (MCP) server? +
MCP is an open standard that allows autonomous AI agents (like Claude Desktop, Antigravity, or custom LLM bots) to securely interface with software. CRX exposes a native MCP endpoint at /api/mcp, giving agents structured tools to look up clients, update deals, and create notes.
How do public CPQ proposals work? +
When an opportunity progresses, sales reps can generate an itemized quote. CRX creates a secure 48-character cryptographic token URL (e.g. /quote/32d55...) that can be sent to clients. The client reviews the proposal and signs digitally—instantly updating your CRM stage to Won.
Is CRX CRM truly free and open source? +
Yes, CRX is 100% open-source under the permissive MIT license. You can self-host, modify, brand, and deploy it for unlimited users and workspaces with zero licensing fees.
